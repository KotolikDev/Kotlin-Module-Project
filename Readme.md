# Консольное приложение "Заметки" на Kotlin

Простое консольное приложение для управления архивами и заметками, разработанное в учебных целях.

## Возможности

- Создание архивов (папок для заметок)
- Добавление заметок в архивы
- Просмотр списка заметок и их содержимого
- Навигация между меню с возвратом на предыдущий уровень

## Технологии

- Язык: **Kotlin**
- Сборка: **Gradle**

## Структура проекта
/src/main/kotlin/

| Файл               | Описание                       |
|--------------------|--------------------------------|
| `Main.kt`          | Точка входа                    |
| `Menu.kt`          | Базовый класс меню             |
| `MainMenu.kt`      | Главное меню                   |
| `ArchiveMenu.kt`   | Меню архивов                   |
| `NoteMenu.kt`      | Меню заметок                   |
| `NoteViewMenu.kt`  | Просмотр заметки               |
| `Models.kt`        | Классы данных                  |
